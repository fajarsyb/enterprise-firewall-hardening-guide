# Panduan Kontribusi

Terima kasih atas minat Anda untuk berkontribusi pada repositori **Enterprise Firewall Architecture & Hardening Guide**!

## Prinsip Kontribusi
1. **Vendor-Agnostic:** Seluruh pedoman harus dapat diterapkan secara umum tanpa condong ke satu merek tertentu.
2. **Berdasarkan Standar Resmi:** Rujukan rekomendasi harus dapat ditelusuri ke standar global seperti NIST SP 800-41, CIS Controls, atau RFC IETF.
3. **Bebas Data Sensitif:** Jangan pernah menyertakan alamat IP publik riil, nama instansi, sertifikat pribadi, atau kredensial rahasia dalam contoh konfigurasi.
